仕入れ電卓 v1.5.0

【インストール（Mac / Windows 共通）】
1. この zip を解凍する
2. できた sourcing-calc フォルダの中に manifest.json があることを確認する
3. Chrome で chrome://extensions を開く
4. デベロッパーモードをオン
5. 「パッケージ化されていない拡張機能を読み込む」
6. sourcing-calc フォルダを選ぶ（zip や一段外のフォルダは選ばない）

【使い方】
1. ツールバーのアイコンをクリックしてサイドパネルを開く
2. 右上の「サイトの設定」を開き、サイトを追加して手数料を入れる
3. 「保存」を押す（保存するまで計算機には反映されません）
4. サイドパネルで出品先・入札先・金額を入れると、結果がすぐ出ます
   （税込売価−販売手数料＝手取。利益率は手取に対して。撮影・販売送料は仕入予算から引く。入札目安は100円四捨五入）
5. 手数料を直したら設定の「保存」で、開いている計算機も更新されます
6. 物色中の価格から見たいときは「現在価格 → 販売目安」

【スマホ（同じ計算ファイル）】
パソコンの拡張機能とスマホのWebは、計算エンジン（calc.js）を共用しています。
設定は端末ごとに保存されます。パソコンとスマホの設定は自動では揃いません。

公開URL: https://jellybeansmame-cloud.github.io/sourcing-calc/

1. スマホのブラウザで上のURLを開く（LINEやメールで送ってタップでよい）
2. Safari / Chrome の「ホーム画面に追加」で、アプリのように開けます
3. 会場など電波が弱いところでも、一度開けばオフラインで計算できます
4. 計算や初期サイトを直したら、同じ公開先を更新してページを再読み込みする

エコリング（ブランド市／道具市）とオークネット（レギュラー／プレミアム）は最初から入っています。不要なら削除してください。

【手数料の種類】
- 一律％（下限円を付けられる。空欄ならなし）
- 価格帯で定額（上限は含む。空欄は「以上」）
- 価格帯で％（該当する帯の％を、金額全体にかける）

【消費税】
- 税率は全体で1つ（初期 10％）
- サイトごとに「落札／販売の本体に消費税」
- 手数料・写真撮影の行ごとに「税別で上乗せ」
- 新しいサイトは最初からオン。税込サイトはチェックを外す
- 送料は入力した金額をそのまま使う

写真撮影は最初からオンです。不要なら外してください。
カード拡張（商品スナップ）とは別物です。同時に入れて問題ありません。
